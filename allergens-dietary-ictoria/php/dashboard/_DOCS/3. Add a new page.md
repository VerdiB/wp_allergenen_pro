# Add a new page

To add a new page you need to create a new directory inside the dashboard directory and a php file with that same name e.g. `dashboard/page_testing-menu/iam-page-testing-menu.php`.

_\*This will assume you are trying to make a submenu and not a top-level page._

```php
// Exit if accessed directly
if (!defined('ABSPATH')) {
    exit;
}
/* Define the new page class and extends
 * `utilities/base_classes/iam-base-page.php` IAM_Base_Page class
 */
class IAM_Page_Testing_Menu extends IAM_Base_Page
{
    /* load each section by title, needs to adhere to class naming structure

     * `IAM_Page_Testing_Menu_Section` will be prepended to each entry
     * e.g. `IAM_Page_Testing_Menu_Section_Landing`
     *
     * The section class name needs to follow this naming logic for
     * the sections to be loaded in autmatically.
     */
    private static $page_sections = [
        /* IAM_Page_Testing_Menu_Section_Landing
         * `page_testing-menu/sections/iam-page-testing-menu-section-landing.php
         */
        'Landing',
    ];

    public function __construct()
    {
        /* Set up the `add_menu_page()` action from the
        * IAM_Base_Page::__construct(
        *   - $page_title,
        *   - $menu_title,
        *   - $capability,
        *   - $menu_slug,
        *   - $callback,
        *   - $icon_url, (only on top-level, default = '')
        *   - $position, (only on top-level, default = null)
        * )
        *
        * https://developer.wordpress.org/reference/functions/add_menu_page/
        */
        parent::__construct(
            'Testing Menu', /* $page_title */
            'Testing', /* $menu_title */
            'manage_options', /* $capability */
            'iam-testing-menu', /* $menu_slug */
            [$this, 'render_page'], /* $callback  */
            '', /* $icon_url (only on top-level) */
            null, /* $position (only on top-level) */
        );

        /* Load in each of the sections added to the $sections array
         * on page creation.
         */
        foreach (self::$page_sections as $section_class) {

            /* $class_name = IAM_Page_Testing_Menu_Section_Landing */
            $class_name = self::$page_base . '_Section_' . $section_class;
            if (class_exists($class_name)) {

                /* Calls `IAM_Base_Page::add_section()`
                 * and adds current $class_name to the sections array
                 * to be used in the autoload function.
                 */
                $this->add_section(new $class_name);
            }
        }
    }

    protected function is_top_level()
    {
        /* For a submenu this is always false */
        return false;
    }

    protected function get_parent_slug()
    {
        /* This has to be the top-level page $menu_slug */
        return 'iam-dashboard';
    }

    /* The render_page() function can be added and
     * will override `IAM_Base_Page::render_page()`.
     * It needs to echo the html one way or another.
     *
     * If left out it will output the default html
     * from `IAM_Base_Page::render_page()` as seen below.
    */

    // public function render_page()
    // {
    //     if (!current_user_can($this->capability)) {
    //         return;
    //     }

    //     echo '<div class="wrap">';
    //     echo '<h1>' . esc_html(get_admin_page_title()) . '</h1>';
    //     echo '<form action="options.php" method="post">';
    //     settings_fields($this->menu_slug . '_options_group');
    //     do_settings_sections($this->menu_slug);
    //     submit_button();
    //     echo '</form>';
    //     echo '</div>';
    // }

}
```

The directory structure of the page should look something like this:

```
dashboard/page_testing-menu/
|- sections/
|- |- iam-page-testing-menu-section-landing.php
|- iam-page-testing-menu.php
```

`iam-page-testing-menu-section-landing.php` is the example from [4. Sections.md](4.%20Sections.md).

You don't necessarily need to add multiple sections for simple pages. It can be usefull if there is a need for having sections linked to different options tables.
