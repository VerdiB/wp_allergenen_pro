# Ictoria Admin Menu

When loading in the [`dashboard/ictoria-admin-menu.php`](../ictoria-admin-menu.php) file it instantiates itself and registers the pages/submenus via an autoloader. Each page extends the [`IAM_Base_Page`](../utilities/base_classes/iam-base-page.php) class.

## Loading pages

It automatically loads all pages that are added into the `$directories` array:

<hr>
<details>
  <summary>$directories</summary>

```php
// IAM_DIR = 'full/path/allergens-dietary-ictoria/php/dashboard'
define('IAM_DIR', __DIR__);

private static $directories = [
    // load base classes
    IAM_DIR . '/' . 'utilities/base_classes/',

    /* top-level menu shows title as 'Ictoria'
    * when clicked submenu title is 'Dashboard'
    * note: submenu title needs to be changed in `iam-base-page.php`
    */
    IAM_DIR . '/' . 'page_ictoria-dashboard/',

    // add more submenus
    IAM_DIR . '/' . 'page_settings/',
    // IAM_DIR . '/' . 'page_another-page/',

];
```

</details>
<hr>

It also loads in the [base classes](./utilities/base_classes/README.md) `IAM_Base_Page` and `IAM_Base_Section`, this is where the main logic of the pages and sections resides, things like child instantiation, hook registration, settings, options etc.

When just adding new pages/sections the base class files do not need to be modified, they can be extended on inside the corresponding page/section file.

In the `__construct` each page that gets added needs to be instantiated:

<hr>
<details>
  <summary>__construct</summary>

```php
private function __construct()
{
    // enqueue assets load methods
    add_action('admin_enqueue_scripts', [__CLASS__, 'iam_style']);
    add_action('admin_enqueue_scripts', [__CLASS__, 'iam_script']);

    /* Instantiation of pages happens here
    * calling the instance in the file itself causes load timing issues.
    */
    IAM_Page_Ictoria_Dashboard::instance();
    IAM_Page_Settings::instance();

    // IAM_Page_Another_Page::instance();
}
```

</details>
<hr>

### Autoloading initial classes

The autoload function loads in all the classes from the `$directories` array so they can be instantiated in the `__construct`:

<hr>
<details>
  <summary>autoload</summary>

```php
public static function autoload($class_name)
{
    /* The $class_name(e.g. IAM_Page_Another_Page)
    * gets converted to $file_name(e.g. iam-page-another-page.php)
    */
    $file_name = str_replace('_', '-', strtolower($class_name)) . '.php';

    // Check if class name starts with `IAM_`
    if (strpos($class_name, 'IAM_') === 0) {

        // Check if the file exists in any of the $directories
        foreach (self::$directories as $directory) {
            $file = $directory . $file_name;

            if (file_exists($file)) {
                require_once $file;
                return;
            }
        }
    }
}
```

</details>
