# Utilities

The utilities directory is for functionality that is not directly related to pages, sections or the main admin menu instance.

## Base Classes

The `base_classes` directory exists for, as the name says, base classes. These are classes that are to be extended upon in its own related file, be it a `page` or `section`.

## Templates

The `templates` directory is to be used for skeleton `page` or `section` files that can be copied for use. Maybe even skeleton directory structures with naming in place. _Might even be possible to make something that automatically outputs those files somehow._
