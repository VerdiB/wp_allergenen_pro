# Templates

The templates can be copied and changed for when you want to make a new `page` or `section`. The only thing you need to keep in mind and change accordingly is the [class & file naming structure](../../README.md).

There are no examples/templates for the top-level menu because there should only be one of those and that is `Ictoria Dashboard`.

The examples can be found in the `dashboard/utilities/templates` directory.
