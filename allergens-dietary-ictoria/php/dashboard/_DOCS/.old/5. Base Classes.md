# Base Classes

Inside the `dashboard/utilities/base_classes` directory the base classes for page as `iam-base-page.php` and section as `iam-base-section.php` exist.

These 2 classes hold the main logic and functionality that register the proper hooks and do the right actions etc. The base classes are abstract classes so that they can be extended upon with separate page/section files, as shown in [3. Add a new page](3.%20Add%20a%20new%20page.md) and [4. Sections](4.%20Sections.md).
