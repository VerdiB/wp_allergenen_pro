# Sections

Each section resides in its parent page directory's `sections` directory. e.g. `page_testing-menu/sections/iam-page-testing-menu-section-landing.php`.

Which would make the classname `IAM_Page_Testing_Menu_Section_Landing` it extends [IAM_Base_Section](../utilities/base_classes/iam-base-section.php).

The instantiation of the section happens in the base section class as well, the call to the [`IAM_Base_Section::register_section()`](../utilities/base_classes/iam-base-section.php) needs to come from the page class `IAM_Page_Testing_Menu` because it needs the `$menu_slug` from it so that gets called during the [`IAM_Base_Page::register_settings()`](../utilities/base_classes/iam-base-page.php) method.

```php
// Exit if accessed directly
if (!defined('ABSPATH')) {
    exit;
}
/* Make sure class is named correctly */
class IAM_Page_Testing_Menu_Section_Landing extends IAM_Base_Section
{
    private static $field_name = '_' . 'field_name';

    public function __construct()
    {
        /* Set up $section_id and $section_title.
         * Also adds a class used with the wrapping
         * div around each section.
         *
         * Each section needs:
         * - $section_id
         * - $section_title
         * - $section_class
         *
         * https://developer.wordpress.org/reference/functions/add_settings_section/
         */
        parent::__construct(
            strtolower(__CLASS__), /* $section_id e.g. IAM_Page_Testing_Menu_Section_Landing */
            __('Landing Title', 'text-domain'), /* $section_title */
            str_replace('_', '-', strtolower(__CLASS__)) /* $section_class e.g. iam-page-testing-menu-section-landing */
        );

        /* Add settings field to `IAM_Base_Section::$fields` array
         *
         * Each field needs:
         * - $field['id']
         * - $field['title']
         * - $field['callback']
         * - $field['args']
         *
         * https://developer.wordpress.org/reference/functions/add_settings_field/
         */
        $this->add_field(
            strtolower(__CLASS__ . self::$field_name), /* $field['id'] */
            __('Landing form Field', 'text-domain'), /* $field['title'] */
            [$this, 'field_callback'], /* $field['callback'] */
            ['label_for' => strtolower(__CLASS__ . self::$field_name),'class' =>
            str_replace('_', '-', strtolower(__CLASS__)) . '-field'] /* $field['args'] */
        );
    }

    /* For each field added there needs to be a callback
     * function that echos the html.
     *
     * As an example I have used the `field_callback()` that echos
     * an input, this is to test if the setting options_group
     * got registered properly in `IAM_Base_Section::register_section()`
     */

    public function field_callback($args)
    {
        $option_value = get_option('iam_page_testing_menu_section_landing_field');

        echo '<input type="text" id="' . esc_attr($args['label_for']) . '" name="iam_page_testing_menu_section_landing_field" value="' . esc_attr($option_value) . '" />';
    }
}
```
